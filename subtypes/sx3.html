3 號的共通核心

以下是 3 號自保型、社交型與一對一型共有的型號說明，取自本站理論指南。能量與八維對應屬於本站的詮釋模型。

3

3 號：為別人的眼睛而活

  • 心區 · 混亂態
  • 原罪：虛榮（Vanity）
  • ≈ Fe / Te

3 號身處心區，心區的能量卻是紊亂的：他不太知道自己真正的感受是什麼，也說不清自己是誰。認同上的真空需要被填滿，最方便的材料就是外界的評價——於是他把自己做成一件會被市場肯定的作品。

這種運作在八維上有兩個出口。走外傾情感（Fe）時，他對群體的反應極其敏銳，擅長塑造符合期待的形象；走外傾思維（Te）時，他以極高的效率達成社會公認的指標：學歷、職位、收入、頭銜。本模型把這種運作理解為借用兩種外傾判斷功能的語言；這是對動機的類比，不表示所有 3 號都具有相同的主導認知功能。

虛榮在這裡的意思因此不是愛漂亮，而是把別人的目光當成自己存在的證明。許多九型作者都指出過，講究績效與自我行銷的現代商業社會，本身就帶著濃厚的 3 號色彩；當一個體制獎勵的正是這種運作，當事人就很難把它看成問題。

  • 原罪：虛榮（Vanity）
  • 一對一型
  • 心區 · 混亂態（依託外界）
  • 本站八維假說：Fe / Te
  • 一般副型

速寫

3 號一對一型是最不像「成功人士」的 3 號。他不太推銷自己的成就，而是把力氣花在成為一個有吸引力的人：理想的男人、理想的女人、理想的伴侶。他的舞台不在眾人面前，而在某個重要的人眼中。

關鍵字：吸引力

Ichazo 曾分別用陽剛之氣與陰柔之氣來描述這個副型。Naranjo 的解讀是：這是過度用力地把自己塑造成文化所推崇的男性或女性形象。問題不在於形象本身，而在於這些行為並非發自本能——他把力氣都用在讓人喜歡上，用力到忘了問自己喜不喜歡、快不快樂。

原罪 × 本能

虛榮在 Sx3 身上縮小成一個問題：我夠不夠有吸引力？Naranjo 認為這是三種 3 號裡依賴性最強的一個。他幾乎不跟人起衝突，可是一被拒絕就受不了；他要的是被喜歡、被肯定，而且常常把「我這個人值多少」直接等同於「我有多吸引人」。他對家庭與伴侶的投入常被當成優點，只是那份投入裡討好的成分太重，日子久了，離自己愈來愈遠。這個副型也常把成就讓給別人：支持伴侶、上司或家人的成功，把對方的光當成自己的光。

日常樣貌

  • 注重外表、儀態與給人的感覺，體貼而略帶害羞。
  • 傾向支持「重要的那個人」，樂於站在對方身後。
  • 一旦被冷落或被拒絕，價值感會迅速崩落。
  • 不太說得出自己真正喜歡什麼，習慣以對方的喜好為準。

容易混淆的類型

最常被誤認為 2 號，兩者都圍著關係轉、都善於討好。差別在於 2 號帶著「你需要我」的驕傲去給予，情緒也較外放；Sx3 給出的則是一個形象，內心較空、較安靜。活潑有魅力的一面又有幾分像 7 號，但 7 號為自己找樂子，Sx3 的快樂要先經過對方的眼睛。

盲點與成長方向

盲點是不知道自己在演，因為演的是「愛」。成長的方向是找回自己的欲望與感受：先從小處分辨「我喜歡」與「他會喜歡」，再去面對不被渴望時浮上來的空與悲傷——那裡面才有真實的自己。當 Sx3 發現即使沒有人注視，他仍然存在、仍然有價值，吸引力就不再是一份全職工作。
